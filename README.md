# Just Excavators

Just Excavators is an independent Fabric mod that brings specialized
area-mining shovels to Minecraft while keeping a predictable, vanilla-style
experience.

Instead of making every upgrade excavate a larger volume, the mod is designed
around distinct excavation profiles:

- Basic: `3x3x1` for general terrain work;
- Deep: `3x3x3` for digging into large volumes;
- Wide: `5x5x1` for clearing and leveling surfaces;
- Advanced: `5x5x3` for high-volume excavation.

Holding sneak disables area mining so that an Excavator breaks only one block.
Future integration with JustHammers will be optional; Just Excavators will
always work as a standalone mod.

## Gameplay

The hit face determines the mining area orientation. Deep always extends into
that face. Only shovel-mineable blocks are affected; protected, unbreakable,
excluded, fluid, and block-entity targets are left alone. Each successful break
uses durability through the normal vanilla flow, preserving enchantments, loot,
XP, and game-mode restrictions.

Each profile is crafted directly at a Crafting Table. A Basic Excavator needs
only its material and sticks; Deep, Wide, and Advanced Excavators use their
corresponding Core in the same tool pattern. The Smithing Table is reserved for
material and enhancement upgrades, including Diamond to Netherite.

## Recipes

Recipes and recipe advancements are generated by `runDatagen`.

- Deep Excavation Core: six redstone dust, an Iron Block, a Netherite Shovel,
  and a Gold Block.
- Wide Excavation Core: six Redstone Blocks, two Gold Blocks, and a Deep Core.
- Advanced Excavation Core: six Redstone Blocks, a Diamond Block, a Wide Core,
  and a Gold Block.
- Basic Stone, Copper, Iron, Golden, and Diamond Excavators: material / stick /
  material; empty / stick / material; centered stick below. Stone uses Stone,
  not Cobblestone.
- Deep, Wide, and Advanced Excavators use the same pattern, replacing the top
  stick with the matching Core. Their mode is stored directly in the result.
- Netherite Excavator: upgrade a Diamond Excavator with the vanilla Netherite
  Upgrade Smithing Template and a Netherite Ingot; its profile is preserved.

`core_model.png` remains a model texture only. There is no Basic Core item.

The Silk Core is registered with its final name and texture, but its recipe and
behaviour are deliberately reserved for the final Silk phase; it is not yet
obtainable in Survival.

## Advancements

The base content includes **Bigger Shovel**, **Digging Deeper**, and **Wide
Open**, earned by obtaining the Iron Excavator, Deep Excavation Core, and Wide
Excavation Core respectively.

## Status

The project is in its initial development stage and currently targets:

- Minecraft 26.3;
- Fabric Loader 0.19.5;
- Java 25.

The complete product vision and planned scope are documented in
[JUSTEXCAVATORS_IDEA.md](JUSTEXCAVATORS_IDEA.md).

## Development

Development requires a Java 25 JDK. Make sure `JAVA_HOME` points to it before
running Gradle.

Build the project with:

```bash
./gradlew build
```

Run data generation with:

```bash
./gradlew runDatagen
```

The generated mod artifacts will be available in `build/libs`.

Generated data is committed in `src/main/generated`. A consecutive
`runDatagen` should not create an unexpected diff.
