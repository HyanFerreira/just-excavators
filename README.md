# Just Excavators

Just Excavators is an independent Fabric mod that brings specialized
area-mining shovels to Minecraft while keeping a predictable, vanilla-style
experience.

Instead of making every upgrade excavate a larger volume, the mod is designed
around distinct excavation profiles:

- Basic: `3x3x1` for general terrain work;
- Deep: `3x3x3` for digging into large volumes;
- Wide: `5x5x1` for clearing and leveling surfaces;
- Advanced: `5x5x3` for high-volume excavation.

Holding sneak disables area mining so that an Excavator breaks only one block.
Just Excavators works standalone. Coexistence with JustHammers is optional and
is covered by the dedicated-server release checks.

## Gameplay

The hit face determines the mining area orientation. Deep always extends into
that face. Only shovel-mineable blocks are affected; protected, unbreakable,
excluded, fluid, and block-entity targets are left alone. Each successful break
uses durability through the normal vanilla flow, preserving enchantments, loot,
XP, and game-mode restrictions.

Each profile is crafted directly at a Crafting Table. A Basic Excavator needs
only its material and sticks; Deep, Wide, and Advanced Excavators use their
corresponding Core in the same tool pattern. The Smithing Table is reserved for
the Diamond-to-Netherite material upgrade.

## Enhancement Cores

Every Excavator has two fixed Enhancement Core slots, managed by the
server-authoritative Enhancement Workbench:

- Silk Core calculates loot with vanilla Silk Touch semantics without storing
  a Silk Touch enchantment on the tool;
- Collector Core sends drops to the player inventory and leaves overflow in the
  world;
- Smelting Core processes drops through current furnace recipes and charges one
  extra durability only when a drop is transformed;
- Filter Core restricts additional area targets to the central block type;
- Void Core discards drops and block XP.

Silk combines with Collector, Smelting, or Filter. Collector combines with
Smelting or Filter. Smelting combines with Filter. Void combines only with
Filter. Duplicate Cores and incompatible enchantments are rejected. Invalid
administrative combinations safely disable Core effects for that break.

The Workbench and all five Cores are registered for Creative mode and commands.
The Workbench and the four newer Cores do not yet have final Survival recipes;
the four newer Cores also still share provisional artwork.

## Recipes

Recipes and recipe advancements are generated by `runDatagen`.

- Deep Excavation Core: six redstone dust, two Iron Blocks, and a Netherite
  Excavator.
- Wide Excavation Core: six Redstone Blocks, two Gold Blocks, and a Deep Core.
- Advanced Excavation Core: six Redstone Blocks, two Diamond Blocks, and a Wide
  Core.
- Core Housing: four Iron Nuggets in the corners and four Iron Ingots around an
  empty center.
- Enhancement Workbench: five Planks around an Anvil, above three Deepslate Tiles.
- Enhancement Cores place a Core Housing in the center, with four units of each
  material alternating around it: String and Emerald for Silk, Ender Pearl and
  Lapis Lazuli for Collector, Magma Cream and Blaze Powder for Smelting, Quartz
  and Amethyst Shard for Filter, and Eye of Ender and Ender Pearl for Void.
- Basic Stone, Copper, Iron, Golden, and Diamond Excavators: material / stick /
  material; empty / stick / material; centered stick below. Stone uses Stone,
  not Cobblestone.
- Deep, Wide, and Advanced Excavators use the same pattern, replacing the top
  stick with the matching Core. Their mode is stored directly in the result.
- Netherite Excavator: upgrade a Diamond Excavator with the vanilla Netherite
  Upgrade Smithing Template and a Netherite Ingot; its profile is preserved.
- Enhancement Cores are installed through the Enhancement Workbench.

`core_model.png` remains a model texture only. There is no Basic Core item.

## Advancements

The main progression starts with **Bigger Shovel**, then alternates between
obtaining each Deep, Wide, and Advanced Core and putting that profile to work
in an Excavator. The enhancement branch starts with **Fine Tuning** and **Power
Needs a Home**, then covers obtaining Silk, Collector, Smelting, Filter, and Void
Cores. **Fully Loaded** recognizes any compatible pair installed on an Excavator,
while **Core Collection** challenges the player to hold all five Enhancement
Cores. **Master of the Earth** still challenges the player to collect Basic,
Deep, Wide, and Advanced Netherite Excavators.

## Development

Development requires a Java 25 JDK. Make sure `JAVA_HOME` points to it before
running Gradle.

Build the project with:

```bash
./gradlew build
```

Run data generation with:

```bash
./gradlew runDatagen
```

The generated mod artifacts will be available in `build/libs`.

Generated data is committed in `src/main/generated`. A consecutive
`runDatagen` should not create an unexpected diff.
